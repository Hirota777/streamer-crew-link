# Streamer crew link v1.1.2

Among Usの色・名前・生存状態をOBSに表示するWindows用の非公式配信補助ツールです。通常版・Nebula・SNRに対応します。Discord不要の「クルーのみ」と、公式Discord Streamkitの画像へ重ねる表示を選べます。

## 旧版から利用する方へ

**v1.1.0は旧設定を引き継ぎません。初回起動で削除内容を確認した後、初期状態から開始します。**

削除対象は旧公開版・Streamkit検証版の対応づけ、表示名、見た目プリセット、Streamkit URL登録、保存認証、既知の設定履歴、更新キャッシュ、OBS連携出力です。新しく保存した設定は2回目以降の起動で削除しません。初回の削除を中止するとアプリを終了し、設定を残します。

旧版が起動中の場合は、先に旧アプリを終了してください。ゲーム・Discordは終了不要です。別のアプリのファイルやOBSのシーン・ユーザーの素材は削除しません。検証版のアプリ本体は別インストールのため、不要ならWindowsの設定からアンインストールしてください。

## ダウンロードとインストール

[最新リリース](https://github.com/Hirota777/streamer-crew-link/releases/latest)から `Streamer-crew-link-1.1.2-Windows-x64.msi` を取得します。Windows 10以降の64ビット版向けです。Node.jsや.NETの別途導入は不要です。

MSIは同じWindowsユーザーの `%LOCALAPPDATA%\Programs\Streamer crew link` にインストールし、旧公開版のアプリを置き換えます。新しい設定の保存先は `%APPDATA%\Streamer crew link` です。配信表示は更新中に止まるため、配信終了後に更新してください。

## 最初の設定

### クルーのみ

1. Among Usを起動してロビーに参加します。ゲームフォルダーへの追加導入は不要です。
2. 配信画面タブで「クルーのみ」を選んで保存します。
3. `http://127.0.0.1:37891/overlay` をOBSのブラウザーソースへ登録します。

ゲーム内の名前とクルー画像を自動表示します。

### Discord画像と合わせる

1. [公式Streamkit](https://streamkit.discord.com/overlay)でVoice・サーバー・通話チャンネルを選びます。Discordへの許可は公式画面で行います。
2. 初期設定で表示先の名前と生成されたVoice URLを保存します。複数の表示先を登録し、メンバータブ上部で切り替えられます。
3. Discordの設定→詳細設定で開発者モードを有効にし、各参加者を右クリック→ユーザーIDをコピーして、ゲーム内プレイヤーに対応づけます。
4. 「OBS連携を開始」を押します。初回はOBSのツール→スクリプトで、連携フォルダー内の `streamer-crew-link.lua` を追加し「配信表示を作成」を押します（OBS 29.1以降）。

ゲーム内にいて、有効なユーザーIDで対応づけ済みの人だけを自動表示します。不在・未対応の人は非表示です。共通の初期アバターは画像URLで識別できず、重ね合わせの対象外です。公式Streamkitの内部データや認証トークンは取得しません。従来のDiscord RPCと保存認証は使いません。

アプリ内のDiscord画像は番号入りの見本です。実際の画像と発言状態はOBSで確認してください。OBSに登録した旧版のLuaスクリプトは外し、本版の連携フォルダーからLuaを追加し直してください。旧ソースとは別に専用ブラウザーソースを作成してください。

## 操作

- 対応づけ・配信用の名前・配信順は自動保存します。失敗時は入力を保持し、再試行できます。
- 「未設定○人」から要確認の一覧を開けます。一覧はすべて／要確認／非表示で絞り込めます。
- 左端のゲーム内プレイヤー名をドラッグするか、矢印で配信順を変更します。実際の配信順は数字で確認できます。一覧ではゲーム内にいる人を優先します。
- 見た目プリセット・保存・元に戻すは配信画面タブにまとめています。表示先の編集は初期設定で別に保存・取り消しします。
- 縦横、画像の形・大きさ、名前位置、背景色、クルー表示、死亡マーク、発言時の高さ（0〜32px）を設定できます。見本には即時、OBSには保存後に反映します。
- 見た目プリセットは書き出し・読み込みできます。対応づけ・URL・認証は書き出しに含めません。自動バックアップはありません。設定一式の手動書き出し・読み込みは初期設定から行います。
- 複数画面の別項目への変更は統合し、同じ項目の競合は保存を止めます。入力は保持し、確認後に最新の対応づけだけ読み直せます。

## 表示の更新と制限

死亡は会議開始、追放は会議終了後に更新します。NebulaのMADMATE巻き添えとSNRの道連れ・後追いは次の会議開始時に反映します。途中起動時は次の会議から同期します。ゲーム本体・MODのバージョンによっては読み取れない場合があります。

ロビー復帰時の一時的な欠落は表示を保持し、ゲーム開始時に更新します。明確な退出は非表示にします。人数の一致は、Discord IDの本人確認や通話への参加・画像表示の成功を保証するものではありません。

連続した見た目更新は約0.75秒まとめ、最大約1.8秒で反映します。停止と表示先切替は待ち時間なしで処理します。カスタムCSSの変更時には[OBSのブラウザー表示が再作成される](https://github.com/obsproject/obs-browser/blob/master/obs-browser-source.cpp)ため、一瞬の再表示は残ります。

OBSの同期を止めると元のURL・CSS・サイズへ戻ります。強制終了時は約10秒後に戻ります。OBS側の手動編集で同期が止まります。

## アプリの更新

起動時に公開GitHubの正式リリースを確認し、利用者が選んだ場合だけ更新します。未保存の編集がある場合は更新を止めます。MSIのサイズ・SHA256・製品識別子・バージョンを検証してから起動します。ゲーム・Discordは終了しません。下書き・プレリリースは自動更新の対象外です。

## 設定一式をZIP版へ引き継ぐ

1. 古いアプリを削除する前に「初期設定」→「設定の書き出し・読み込み」→「設定一式を書き出す」で、任意の場所へJSONを保存します。
2. 新しいZIPを展開して起動し、同じ欄の「設定ファイルを読み込む」でJSONを選択します。
3. 件数と選択中の見た目を確認し、「現在の設定に置き換える」を押します。OBS連携は停止するため、表示を確認してから再開してください。

対応づけ・配信用の名前・順序、表示先の名前とStreamkit URL、すべての見た目プリセットと選択状態、OBS自動開始の設定を引き継ぎます。通常の設定保存先は従来どおりAppDataです。ZIPの展開フォルダーへ保存する変更は行っていません。Windowsの暗号鍵、認証情報、通話内容、更新キャッシュ、OBS本体のシーン設定は書き出しません。更新確認の設定も別管理です。

設定一式のJSONは平文で、ユーザーID・名前・Streamkit URLを含みます。公開・共有せず保管してください。見た目プリセットだけの書き出しとは別形式です。読み込み時は現在の設定を置き換えるため、残したい設定は先に書き出してください。確認後の他画面による変更や不正な形式は、上書きせず拒否します。

「あとで」は今回の通知を閉じ、起動時の自動確認が有効なら次回また通知します。「スキップ」は同じ版の自動通知だけを停止し、新しい版は対象にします。手動の「更新を確認」ではスキップした版も表示します。操作後の案内と初期設定のスキップ中表示で区別できます。

[導入手順書・機能仕様書・制御仕様書](https://github.com/Hirota777/streamer-crew-link/tree/main/docs)はGitHubで提供しています。PDFはアプリのMSI・実行用ZIPには同梱しません。
