# Streamer crew link 0.7.2 — Windows配布テスト版

Among Usの色とDiscordの参加者・発言状態を対応づけて、OBSに表示する非公式ツールです。
現在はDiscordで利用を許可されたテスター向けです。一般公開の承認が完了したことを示す配布物ではありません。

## 使い始める

1. ZIPをフォルダーに展開し、Streamer crew link.exeを起動します。実行ファイルだけを移動せず、同梱ファイルを一緒に置いてください。
2. Discordデスクトップ版を起動し、サーバーの通話へ参加します。
3. アプリの「接続」画面で「Discordと連携・許可」を押します。ブラウザーで自分のDiscordアカウントと表示されたアプリ名を確認して許可してください。
4. Among Usを起動してロビーに参加します。Nebula・SNRを使う場合も、ゲームフォルダーにこのツールのファイルを追加する必要はありません。
5. 「メンバー」画面でゲーム内の名前とDiscordの参加者を対応づけ、画面下の「変更を保存」を押します。

Application ID・Client Secret・Redirect URIの入力は不要です。
許可した認証の保存を有効にすると、次回は自動接続します。Discordが後から起動する場合も待機します。
ブラウザーの許可を取り消した場合や認証が無効になった場合は、もう一度連携してください。

## OBSに表示する

「配信画面」の「URLをコピー」で、OBSのブラウザーソースに設定できます。
ブラウザソースURL：http://127.0.0.1:37891/overlay
推奨サイズ：1920 × 300。背景は透明です。表示人数・サイズに応じて調整してください。
アプリが動作している間に利用できます。
デモは架空の11人です。デモ中はOBSにもDEMOと表示します。本番では「実際の接続に戻る」を押してください。

## 保存と終了

ウィンドウを閉じるとアプリ・読取処理・OBS表示が終了します。
個人設定は %APPDATA%\Streamer crew link に保存します。配布フォルダーやZIPには保存しません。
認証はWindowsで暗号化して保存します。「今回は切断」は今回の自動再接続を止め、「保存した認証を削除」はこのPCの保存認証を削除します。
名前を変更したゲーム参加者は、対応づけの再設定が必要です。同名の参加者が複数いる場合は取り違えを避けるため該当者を表示しません。

## 対応範囲

Windows x64向け。Discordデスクトップ版と、対応表に一致するAmong Usが必要です。
ゲームを外側から読み取ります。ゲームへのファイル追加、コード注入、メモリー書き込みは行いません。
通常18色の指定素材を同梱しています。Nebulaの動的カラーとSNR 3.3.0.0の64追加色に対応します。SNRの標準18色は指定素材を使用し、追加色は本体色・影色で描画します。
ゲーム・Nebulaの更新や、異なる端末との同時参加の可否はゲーム本体側の対応に依存します。
別PC・各端末・Nebula併用・長時間配信の確認は、配布先環境でも行ってください。

## 認証できないとき

Discordのテスター登録と招待の受諾を配布者に確認してください。公開クライアントにしただけでは、未承認RPCアプリを誰でも利用できるようにはなりません。
ポート37891が他のアプリで使用されている場合は、使用中のアプリを確認してください。

データの扱いはPRIVACY.md、配布者向け手順はDISTRIBUTION.mdをご覧ください。
このツールはInnersloth、Discord、Nebulaの公式製品ではなく、これらの提供者による推奨・後援を受けたものではありません。

## 0.5.0の変更
初期ウィンドウを1050×760に縮小しました。NebulaはプレイヤーIDに紐づく本体・影・バイザーの動的RGBを読み取って表示します。取得できない場合は標準色へ置き換えず、取得待ちを表示します。ゲームフォルダーへの追加導入はありません。実際のNebulaロビーでの確認は未実施です。

## 0.5.1の修正
Discordの通話退出後に「接続中」が残る問題を修正しました。チャンネル移動中の更新、切断後の遅い応答、発言状態の消去、許可待ちでの切断も見直しました。自動テスト34件を確認しています。

## 0.5.2の修正
デスクトップ版の「URLをコピー」が動作しない問題を修正しました。OBS用URL専用のコピー処理を設け、実際のWindowsクリップボードに正しいURLが入ることを確認しています。

## 0.6.0の変更
SNR3.3.0.0の追加色に対応しました。BepInEx/plugins内の既存SuperNewRoles.dllをデータとして読み、埋め込まれた64色を使用します。DLLの実行・ゲームフォルダーの変更は行いません。未確認バージョンや不正な色は取得待ちとなります。Among Us本体も同梱対応表との一致が必要です。SNR・Nebulaの同時導入は対象外です。

セキュリティ点検に基づき外部サイトからのアクセス制限と表示接続数制限を追加し、Electron 45.2.3と作成用依存ライブラリの修正版へ更新しました。詳細はSECURITY-REVIEW.mdをご覧ください。自動テスト39件、読取自己診断、SNR公式DLLからの色取得を確認しました。実際のSNRロビーでの確認は未実施です。

## 0.7.0の変更
小さいウィンドウに合わせ、操作を「配信画面・メンバー・接続」の3画面に整理しました。接続状態と次に必要な操作を案内し、OBS用URLと保存操作を見つけやすくしました。対応づけと表示設定は保存前にプレビューへ反映されます。OBSへの反映には画面下の「変更を保存」を押してください。「変更を元に戻す」で未保存の変更を取り消せます。プレビューは人数に応じて全体を縮小し、OBSの出力サイズは保存した設定を使います。初期ウィンドウサイズと保存済みの設定・認証は引き継ぎます。

自動テスト39件に加え、画面の切り替え、キーボード操作、11人のプレビュー、保存・取り消し・即時プレビュー、幅780／1050／1440での表示を確認しました。

## 0.7.1の変更
表示名をSNRに統一しました。対応バージョンは接続画面の「対応バージョンについて」に記載しています。

## 0.7.2の修正
Nebulaの実際のロビーで色を取得できない問題を修正しました。ゲーム付属のMicrosoft .NET 6.0.7の診断ライブラリに、新しい署名判定が要求する専用の証明書用途がないことが原因でした。署名確認済みのMicrosoft公式パッケージとハッシュが完全一致する実行基盤・診断ライブラリの組み合わせだけに互換処理を設けています。他のファイルには通常の署名確認を適用し、ゲームのファイルは変更しません。

このPCで起動中のAmong Us v19sとNebulaから、本体・影・バイザーの32要素の色配列とロビー参加者の色を確認しました。別PCや他のNebula版・複数参加者での確認を完了したものではありません。取得失敗時は、待機表示に加えて署名・形式・読取の案内を表示します。
