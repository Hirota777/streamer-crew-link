# Code of conduct

Treat contributors and users respectfully. Harassment, discrimination,
threats, doxxing and the publication of private credentials are unacceptable.
Keep technical discussions constructive and respect third-party rights.

Hirota777 maintains this project and reviews external contributions. The
maintainer may remove abusive content or restrict participation for violations.
Reports can be raised through GitHub Issues without including personal data.
For a sensitive report, first request a private contact method without posting
incident details. Do not publish tokens, private messages or personal information.
