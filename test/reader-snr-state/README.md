# SNR managed state and timing regression

Build Fixture.csproj and the test-only reader-meeting-probe/Probe.csproj, then run check.mjs with dotnet, probe executable, and fixture DLL paths. The fixture creates an uninitialized duplicate SNR module to verify selection of the live initialized module. It covers the exact private player-list property, nullable final statuses, three collateral kinds, normal exile and meeting/wrap fields. No role, killer, location or task field exists in the fixture.

The shared test/reader-life project covers deferred revenge/lovers/vampire deaths, native target missing, delayed raw exile flag, skipped vote, durable Airship marker, initial baseline, next meeting release and new-round reset. Real multiplayer meetings remain unverified.
