# Streamer crew link v1.1.7

## OBS連携の自動復旧

- 連携ファイルの書き込み失敗で停止した場合、2秒・5秒・10秒、以降30秒ごとに再試行します。
- 連携の表示ファイルが消えた場合も検出し、再生成します。
- 復旧時には保存済み設定と最新の実ゲーム情報から表示を作り直します。デモの参加者は配信しません。
- 復旧待ち中は「復旧を試みています」と表示します。連続失敗時は保存先の空き容量・アクセス権の確認を案内します。
- 手動の一時停止・表示方式の変更・URL削除・設定一式の読み込み・アプリ終了では再試行を取り消します。
- 正常な間は同じ表示を書き直さず、既存のOBSソースを使います。OBS側でURL・CSSを編集した場合の同期停止は維持します。

自動復旧はアプリの連携ファイルが対象です。Discord／Streamkitの接続や、OBSが実際に描画できていることを監視・保証する機能ではありません。OBS側のスクリプトは従来どおり、正常なファイル更新が戻ると反映を再開します。

設定の保存先・保存形式・初回移行条件はv1.1.6から変更していません。
