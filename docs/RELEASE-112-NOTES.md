# Streamer crew link v1.1.2

設定一式の書き出し・読み込みを追加しました。ZIP版を手動で入れ替える際などに、選んだファイルから設定を引き継げます。

## 変更点

- 初期設定に「設定の書き出し・読み込み」を追加。デスクトップのファイル選択画面で保存先を指定できます。
- メンバーの対応づけ・表示名・順序、Streamkitの表示先とURL、見た目プリセットと選択状態、OBS自動開始設定をまとめてJSONへ書き出します。
- 読み込み前に件数を表示し、確認後に現在の保存設定を置き換えます。OBS連携とデモは停止するため、表示を確認してから再開してください。
- 不正なファイル、未保存の編集、読み込み確認後の別画面からの変更による上書きを防ぎます。
- 更新通知の「あとで」と「スキップ」の違いを画面で案内します。「あとで」は次回起動時に再通知。「スキップ」は同じ版の自動通知を停止します。手動確認ではスキップした版も表示し、次の新しい版は自動通知の対象です。起動時の自動確認が有効な場合の動作です。

## 設定の引き継ぎ

v1.1.0・v1.1.1で保存した設定はそのまま使用します。設定の保存先は従来のAppDataです。ZIPの入れ替えにあわせて、この保存先を削除しないでください。

書き出し機能はv1.1.2から利用できます。まず更新して設定が表示されることを確認し、初期設定から書き出してください。削除済みの設定を復元する機能ではありません。読み込みは既存設定への追加ではなく置き換えです。

書き出したJSONにはユーザーIDと表示先URLが含まれます。共有せず保管してください。認証トークン・暗号化キー・通話内容・更新履歴・OBS本体のシーン設定は含みません。見た目だけのプリセットJSONとは別形式です。

v1.0系から初めてv1.1系へ更新する場合は、初回確認後に旧設定を初期化する仕様です。配信終了後にアプリを閉じ、MSIで更新するかZIP版を展開して使用してください。ゲームとDiscordは終了不要です。Source codeは実行用ではありません。

## 検証と既知の不具合

単体・サーバーテスト164件、画面テスト47件の計211件が成功。Windowsの異なる保存プロファイル間で書き出し・読み込み・再起動後の保持を確認しました。MSIとZIPの40ファイルが配布アプリと一致することを確認しています。

次の2件は既存の未修正事項です。

1. デモ表示中、実ゲームの更新や保存した表示方式がOBSへ反映されず、デモ終了後に反映される。配信中は通常表示で操作してください。
2. 複数の設定画面で同じ見た目を編集すると、後の保存で別画面の変更を古い値へ戻す場合がある。見た目の編集は1つの設定画面で行ってください。

実ゲーム・複数人の通話・OBSを通した一連の動作確認は未完了です。CSS変更時のOBSの一瞬の再表示は残ります。
