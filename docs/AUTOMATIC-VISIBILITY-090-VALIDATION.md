# 0.9.0 メンバー表示の自動判定

## 仕様

- game.displayPlayersに存在し、有効なDiscordユーザーIDで対応づけられた人だけをStreamkitと見本に表示。未登録・不正ID・不在の登録は表示しない。旧visible=falseも判定に使わず、在室・対応済みなら自動表示する。
- メンバー表の手動チェックを「表示／非表示／保持中」の状態表示へ変更。非表示の一覧には不在・未対応を表示。上部の人数照合では旧visibleフラグを除外条件にしない。
- 在室変化で対応づけを自動保存・削除しない。表示順と登録内容は保持する。見本と出力枠サイズも不在者を除外し、余計な名前・画像・空白を出さない。
- ゲームの生データの一時欠落では従来のロビー復帰保持を利用し、表に保持中と表示。明確な退出通知は即時反映する。通常の読取欠落の保持は最大10秒、ロビー遷移の保持は最大60秒。死亡状態の更新タイミングは変更しない。

## 検証

単体145件・画面43件、合計188件成功。新規3件で、旧手動OFFがある在室・対応済みの人の表示、不在者・未登録者・不正IDの非表示、余白計算、APIの見本と配信情報の一致、退出・再参加・解除・再読込、ロビー保持と期限切れ、在室変化で保存しないことを確認。

旧手動表示前提の回帰テストは自動表示へ更新。負荷が高い全画面テストでも合成ゲーム情報が5秒で期限切れにならないよう、2つのレイアウト／一覧テストの時刻を固定した。実アプリの期限は変更していない。

利用者の起動中アプリ・ゲーム・Discord・OBSと保存設定は操作していない。非公開Streamkit版の更新であり、中止済みの公開版後継リリース準備は再開していない。
