# 0.4.0 メンバー対応づけの共通化

2026年11月13日。非公開Streamkit版が対象です。

メンバープリセットの選択・作成・複製・名前変更・削除・書き出し・読み込みを廃止しました。対応づけ、表示名、表示ON/OFF、配信順、Streamkit URLは1つの共通設定へ保存します。見た目プリセットは従来どおり管理できます。

更新時は選択中の対応づけとURLを引き継ぎます。他のメンバープリセットを勝手に結合しません。移行前の暗号化ファイルは既存の3世代バックアップへ保存します。過去のバックアップを復元してもメンバー切替機能は復活せず、その時点で選択されていた対応づけを共通設定へ移行します。保存先IDの互換性のため内部ファイルには1件の旧形式スロットを保持しますが、作成や切替のAPIは提供しません。

一覧はゲーム内にいるプレイヤーを優先し、未登録のゲーム参加者も不在の保存メンバーより上に置きます。各グループ内の順序は安定させ、保存済みの配信順やOBSの並び順をこの表示ソートで変更しません。入力中は一覧の描き直しを避け、入力後に参加状態を更新します。

全自動テスト155件（単体・サーバー・Lua模擬131件、画面24件）が成功しました。移行元2プリセットからの選択中データの保持、移行前のバックアップ、廃止APIの拒否、見た目切替後の共通URL、ゲーム参加・退出中の編集保持、保存後の再読込を確認しました。

Windowsでは隔離した合成データを使い、ElectronのsafeStorageによる暗号化設定の移行・別プロセス起動後の保持・バックアップ復元を確認しました。利用中のアプリやOBSは終了せず、実ユーザーの設定・認証・暗号化キーをコピーしていません。新しいMSIで実ユーザー環境を更新した確認は未実施です。

公開版のリポジトリとリリースは変更しません。更新用の非公開版MSIを作成します。ゲームの読取、死亡更新の時期、OBSの標準描画・背景は変更していません。
