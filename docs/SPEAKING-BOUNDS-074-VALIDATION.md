# 0.7.4 発言アニメーションの枠内配置

## 再現と修正

大きさ160px・動き強の発言アニメーションを頂点で停止すると、クルーの上端がメンバー行の上端を約11.2px超えることを再現。出力全体の余白はあったが、各メンバーの背景枠内に移動分が確保されていなかった。

アニメーションON時だけ、上方向の移動量と白縁に必要な上余白、死亡マークが下へ出る場合の下余白を各行の寸法に含めた。画像・クルー・名前・マークの位置と出力サイズに反映し、プレビューとOBSで同じCSSを使用する。OFF時の寸法や公開版に合わせた静止配置は維持する。

単体141件・画面38件、計179件成功。新規テストで横・縦、通常・最大サイズ、強い動き、クルー非表示、名前非表示、倍率160%、背景OFFを含む8条件を、0・240・480msの3時点で停止。画像・クルー・死亡マークが各メンバー枠の上下に収まることを確認。既存の最大50人の出力範囲、公開版との静止配置比較も成功。
