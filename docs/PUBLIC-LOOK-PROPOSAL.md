# 公開版の配信表示にそろえる修正案

検討日：2026年11月13日。対象は非公開Streamkit版0.3.1の配信表示です。アプリの設定画面ではなく、OBSへ表示するクルー・Discord画像・名前・死亡マークを比較しました。公開版リポジトリのHEAD 5897104の描画ファイルは作業ツリーで未変更であることを確認しました。公開版のソース・配信中のOBS設定は変更していません。

## 結論と導入方法

公開版の配置・比率・文字・装飾を基準に、StreamkitのカスタムCSSを調整することで見た目を近づけられます。当初は「公開版風」の追加プリセットを提案しましたが、利用者の指示により0.3.2の標準描画として採用しました。追加プリセットは作りません。保存済みの丸型・サイズ・名前位置や、現在選択中のプリセットを自動で上書きしません。従来のStreamkit表示も保持します。

認証や参加者取得の方式を公開版へ戻すものではありません。公式Streamkitの内部データ取得、RPCの制限回避、公式アプリの認証情報流用は行いません。

3人の同一比較データで横・縦の4つの見本を描画し、クルー寸法、画像の角丸、暗くする対象の違いを計測しました。Streamkit側はアプリ内見本のCSSクラスを使っています。実際の公式Discord画像や通話を収集した比較ではなく、公式ウィジェットのすべてのスタイルを再現するものではありません。

## 実装を分ける順序

1. 配置の共通計算を用意します。画像サイズ、クルーの幅・高さ、間隔、名前の領域、死亡マーク、背景余白、アニメーションの移動量から各要素の矩形とOBS枠を一度だけ計算します。公開版風CSSとアプリ内見本が同じ値を使います。
2. 形・クルー比率・間隔・名前・死亡マークを標準の描画へ適用します。公開版そのものは変更しません。
3. 非発言時の暗さ・キャラ色の発言枠・アニメーション・背景余白を調整します。発言状態は公式Streamkit側のクラスに応じてCSSで表現し、アプリへ抽出しません。
4. 横／縦、名前の下／重ね／右、クルーON/OFF、死亡、生存、文字40px、倍率160%、長い名前、背景ON、複数列までを描画テストで確認します。同じ入力の矩形と画像を比較し、意図した差を記録します。
5. OBSでは公式Streamkitの実画像で、1人の通常・発言中・死亡表示を確認します。複数人の入退室と表示順は実環境で別途確認し、未実施を成功扱いしません。保存処理やゲーム読取を変えない限り、それらの手動再テストは増やしません。

## 完全一致の対象外と注意点

- 公式Streamkitに存在しない参加者のDiscord画像をアプリから追加表示することはできません。未登録の参加者や、IDを識別できない共通の初期アバターも表示対象外です。
- アプリは実際の通話人数・入退室・発言情報を収集しません。画面の登録数と実際の表示人数を同一視しません。入室順や余白は複数人で実確認します。
- 表示名の優先順位を明確にします。手動の配信用表示名があればそれを使い、未指定時は公式Streamkitの名前を維持します。ゲーム名とDiscord名は一致しない場合があるため、完全一致を求める場合は表示名を設定します。
- 公式ウィジェットのクラス・画像URLの変更には影響を受けます。適用後のOBSでの確認が必要です。
- レイアウトの寸法が変わるため、OBSソースの切り抜き・拡大率・配置に影響する可能性があります。既存の見た目設定を上書きせず、別プリセットで確認します。
- 通常死亡は会議開始時、追放は会議終了後、巻き添えは次の会議開始時という現在の公開タイミングは変更しません。

## 今回の成果物

0.3.2で標準描画として実装しました。公開版の基準CSSを用いた比較テストで、背景ON/OFF・縦横・名前の配置・クルー非表示時の寸法と配色を照合します。現在起動中のアプリとOBSの実設定は自動変更せず、更新用MSIを用意します。公開リリースは行いません。
