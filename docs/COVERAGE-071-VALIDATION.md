# 0.7.1 人数照合と状態欄の整理

- ゲーム接続状態の読取方法の補足、表示対象の「実際の通話人数ではありません」を常時表示から削除。読取の詳細はゲーム状態のタイトルに残す。
- 登録総数から、現在ゲーム内にいて表示ON・有効なDiscord ID登録済みの人数へ変更。不在登録は照合対象外。「全員対応済み」または「未設定N人」を同じ状態欄に表示。
- クルーのみは現在のゲーム参加者を自動表示、デモはデモ表記。未接続・0人では全員対応済みとしない。
- 対応先が正しい本人か、Discord通話に参加しているか、画像が取得可能かは判定していない。OBSの表示完了を示す意味にしない。配信描画や保存形式は変更していない。
- 単体137件・画面34件、計171件成功。新規テストで、不在の登録と未登録者が相殺して総数だけは一致するケース、全員登録、表示OFF、不正ID、クルーのみ、デモ、0人を確認。
- 起動中のユーザーアプリ・ゲーム・Discord・OBSは終了・変更しない。
