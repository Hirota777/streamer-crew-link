# 0.3.2 標準配信表示の修正と検証

2026年11月13日。非公開Streamkit版が対象です。「公開版風」の追加プリセットを作らず、標準の描画を公開版へ合わせました。新規設定の画像形状は角丸12pxです。既存の丸・角丸・四角の明示選択、サイズ、名前位置などは維持します。

キャラ色背景は行全体に付け、内側余白8px、角丸4px、縦表示での背景幅の統一を適用します。クルーを非表示にした場合は左のクルー用領域もなくなり、名前を右に出した場合はその領域まで背景を付けます。背景OFFでは余白を外し、横表示の名前の背景を透明に戻します。色が未確定の参加者へ古い背景色は付けません。

クルーの幅0.72倍・高さ0.81倍、縦の間隔12px、名前の文字影・行高・背景、死亡マークの位置をそろえました。非発言中は画像のみ明るさ60%、発言中はキャラ色の枠と光、標準の動きは0.48秒・画像サイズの8%です。背景は動かさず、クルーと画像・×・重ねた名前を動かします。縮小アニメーション設定にも対応します。

公開版コミット5897104の未変更CSSをtest-support/public-overlay-reference.cssへ検証用に保存し、背景ON/OFF・縦横・名前位置・クルー非表示の6ケースで寸法（1px以内）・配色・余白・暗くする対象を比較するテストを追加しました。最大50人、最大倍率、最小画像と最大文字での見切れの既存テストも実行します。基準CSSと開発テストは配布物へ含めません。

全自動テスト152件（単体・サーバー・Lua模擬129件、画面23件）が成功しました。比較画像は番号入りの仮画像を使った描画確認です。今回の修正を実際のOBSと複数人のゲーム・通話で通した確認はまだ実施していません。保存形式・ゲームの死亡情報公開タイミング・認証方式・Luaのソース復元処理は変更していません。

既存のソースの拡大率や切り抜きにより見え方が変わる場合があります。更新後にOBSで位置を確認してください。起動中アプリ・実際の配信設定は自動変更しません。公開版リポジトリへの反映とリリース公開は行いません。
