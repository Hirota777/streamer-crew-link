# 0.5.0 名前付きStreamkit表示先

確認日：2026年11月13日。非公開Streamkit版が対象です。

初期設定の「表示用URLを設定・変更」で任意の名前と公式Voice表示用URLを入力し、「表示先を保存」で登録します。別の表示先は「新しく登録」で作成します。保存した表示先はメンバータブ上部の「Streamkitの表示先」で選びます。登録済みの名前・URLは入力欄を閉じたり読み取り専用にしたりせず、そのまま編集できます。登録の削除には確認を表示します。

表示先には名前とURLだけを最大30件保存します。対応づけ一覧・表示名・表示ON/OFF・配信順は全表示先で共通です。見た目プリセットも表示先ごとに変えません。メンバープリセット機能は再導入しません。表示先を保存する処理と、メンバー／見た目を保存する処理を分離しました。表示先名は1〜80文字で、重複した名前は拒否します。

0.4.1以前の保存URLは「登録済みの表示先」として移行します。移行前は既存の暗号化3世代バックアップへ残します。登録一覧と選択中の表示先も暗号化設定に保存し、再起動・バックアップ復元・全削除へ対応します。見た目JSONの書き出しに表示先一覧やURLを含めません。OBSへ渡すURLは選択中の1件だけです。

表示先切替は未保存の対応づけ・見た目を保持します。名前・URLが未保存の場合は明示保存か元に戻す操作を案内し、勝手に捨てません。別画面で切り替えられたあとに古い表示先を保存しても、現在の選択を巻き戻しません。同じ登録の更新・削除は版番号を照合し、古い編集で新しい内容を上書きしません。バックアップ復元でも版番号を進め、復元前の編集を拒否します。古い保存応答が遅れて届いても状態番号で逆戻りを防ぎます。

全自動テスト164件（単体・サーバー・Lua模擬136件、画面28件）が成功しました。新規登録・再編集・切替・削除、対応づけと見た目の独立、別画面の競合、応答遅延、名前・URL・件数の検証、CSRF保護、選択URLのOBS連携ファイルへの反映を確認しました。

Windowsでは、隔離した合成データでElectron safeStorageを使用し、旧URLの移行・複数表示先の暗号化保存・別プロセス起動後の保持・旧バックアップの復元を確認しました。実ユーザーの設定・認証・暗号化キーはコピーしていません。

登録・選択だけで公式ページを開いたり、Discord参加者・発言情報を取得したりしません。OBS連携中は選択URLへの切替が既存Lua同期へ反映されます。今回、利用中のOBS・アプリは変更していません。実際の複数人通話・ゲームを通した一連の確認は未実施です。Luaの同期・ソース作成・復元処理とゲームの死亡更新時期は変更していません。

公開版のリポジトリと公開リリースは変更しません。更新用の非公開版MSIを作成します。
