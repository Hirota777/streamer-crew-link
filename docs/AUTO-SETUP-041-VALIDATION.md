# 0.4.1 OBS配信表示の作成ボタン

確認日：2026年11月13日。非公開Streamkit版のみが対象です。

OBSの連携スクリプトへ「配信表示を作成」を追加しました。アプリでOBS連携を開始したあとボタンを押すと、選択中のシーンへ専用ブラウザーソースを追加し、URL・CSS・サイズ・対象UUID・同期開始をまとめて設定します。スタジオモードではプレビュー側へ追加します。公式Streamkitの表示と既存のLua同期を使い、ローカルURLへの転送や内部データの取得は追加しません。

専用ソースのUUIDと所有マーカーで再利用します。別シーンでは同じソースを追加し、同じシーンでは重複を作りません。改名後も再利用します。削除後はボタンによる明示操作で再作成し、同名の他のソースを上書きしません。アプリ連携の停止・終了時は空の表示へ復元し、ソース自体は残します。すでに手動で選択したソースを使っている場合、作成ボタンを押す必要はありません。

アプリ未起動・連携停止中・期限切れ・不正なURLやデータ・シーン未選択・ソース作成失敗・シーン追加失敗では処理を中止します。失敗した新規ソースだけを取り消し、参照を解放します。手動選択した不在ソースの復元情報は勝手に破棄しません。専用ソースが削除された場合だけ、明示操作でその旧復元情報を置き換えます。

全自動テスト156件（単体・サーバー・Lua模擬132件、画面24件）が成功しました。新しいLuaテストで、前提条件・失敗とロールバック・連打・改名・シーン間の再利用・スタジオモードのプレビュー・スクリプト再読み込み・停止・手動編集・削除後の再作成・所有確認・参照解放を検証しました。既存の復元・タイムアウト・ソース不在・同名ソース保護のテストも成功しました。

隔離したポータブルOBS 33.0.1でも実際のソースAPIを呼び、作成・URL/CSS/サイズの設定・連打・改名・同じシーンでの再利用・手動編集保護・停止・スクリプト再読み込み・削除後の再作成・同名ソースの保護を確認しました。この試験ではブラウザーを非表示・非使用時終了にし、Discordの画像・認証は確認していません。実際のゲーム・複数人の発言を含む一連の確認は未実施です。

利用中のOBS・アプリ・ゲーム・Discordは終了・変更していません。更新後はアプリの連携を開始し、OBSでスクリプトを再読み込みしてください。公開版リポジトリと公開リリースは変更しません。
