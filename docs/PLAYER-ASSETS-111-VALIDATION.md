# v1.1.1 素材差し替えの確認

確認日：2026年11月16日。利用者の指定により、以前の36枚と、それを使用したアプリアイコンを置き換えました。公開リリースと利用中のアプリは変更していません。

## 出典と変更

- 配布元：automuteus/amonguscapture、コミット `7038d375b9eacd97d8352bcc0f5a090fc3ab6a28` のAUCapture-WPF/Resources/Players。
- 参照フォルダー24枚のGit blob SHAが、GitHubから取得した一覧24枚と一致することを事前に確認。
- 元12色の24枚を使用。生存12枚は元ファイルと一致。Dead12枚は白縁で背景が四角く浮く問題を避けるため、alpha値3以下だけを透明化。
- 追加6色×生存・Deadは、新しいシアンのテンプレートと既存のゲーム色パレットから生成。Nebula・SNRの動的変換も新テンプレートの色へ対応。
- アプリアイコンは同じシアン素材から再作成。
- `assets/players-source.json` に元画像と配布画像それぞれのSHA256、加工内容、派生パレットを保存。再生成は `python scripts/replace-player-assets.py <AmongUsCaptureのチェックアウト>`。
- 出典・Copyright (c) 2020 Denver Quane・MIT条件を明記。独立した `LICENSE-AmongUsCapture-Players.txt` を同梱し、アプリのライセンス画面からも表示。

## 検証

- 単体156件成功。
- 画面44件のうち、全体実行で43件成功。残る1件は初回ゲーム情報が5秒を超えて古くなるテスト環境の問題を確認し、実際のReaderと同様に定期送信する環境へ修正。同ファイルの3件を再実行してすべて成功。最終的に全200項目を確認。
- 新規テストで36枚のハッシュ、アイコンの埋め込み元、MIT表記、生存・Dead・追放の動的色変換、骨・血・透明部分の保持を検証。
- Windows nativeImageによるOBS画像変換も成功。赤いbody画素3822、Alive・Deadが異なり、幅128の出力を確認。
- v1.1.1アプリ内の36画像はマニフェストと一致。画像変換コード・ライセンス経路もソースと一致。個人設定の同梱なし。
- MSIをインストールせず展開し、40ファイルすべてが配布アプリと一致。製品バージョン1.1.1、従来のUpgradeCode、ユーザー単位の導入先を確認。インストール済み製品の状態は変更していない。
- MSI SHA256：`beae1978477328d671206c35348c2c9a0ce8577f55c5f3658827996f6423c0eb`。

## 対象外・未反映

この変更は素材差し替えと関連する色変換・ライセンス表記だけです。前回報告したデモ中のOBS更新停止と、複数画面の見た目保存による上書きの2件は修正していません。実ゲーム・複数人の通話・OBSを通した一連の確認は未実施です。

確認用MSIを作成した段階で、GitHubの公開リリース、公式サイトの画像、利用者の現在のインストールには反映していません。Among Us原作IPに関する規約適合の未確認事項は、MIT素材への差し替えだけで解消するものではありません。
