# Streamer crew link v1.1.0

**この版は旧設定を引き継ぎません。初回起動で案内を確認し「削除して開始」を選ぶと、旧公開版・Streamkit検証版の設定・対応づけ・見た目・URL登録・保存認証・アプリ専用キャッシュを削除し、初期状態から開始します。** 新しく保存した設定は次回起動でも維持します。

## 主な変更

- Discord RPC方式から、公式Discord StreamkitとOBSの連携方式へ変更。Discordなしのクルーのみ表示も利用できます。
- 対応づけは自動保存。ゲーム内にいる対応済みメンバーだけを自動表示します。
- 配信画面用の見た目プリセット、未対応者の絞り込み、名前のドラッグによる配信順変更に対応。
- 画像・名前・背景・クルー表示・発言アニメーションの高さを設定できます。
- 複数画面の編集の上書きを防止し、OBS向けの連続更新を集約して再読み込みを抑えました。CSS変更時の一瞬の再表示は残ります。

## インストールと再設定

1. 配信終了後に旧Streamer crew linkを終了し、`Streamer-crew-link-1.1.0-Windows-x64.msi` を実行してください。ゲームとDiscordは終了不要です。
2. 初回起動で削除対象を確認して開始してください。削除を中止すると設定を残して終了します。
3. クルーのみの場合はOBSへ `http://127.0.0.1:37891/overlay` を登録してください。
4. Discord画像を使う場合は、公式StreamkitのURLと各メンバーのユーザーIDを登録してください。OBSの旧Lua登録を外し、本版の連携フォルダーのLuaを追加して「配信表示を作成」を押してください（OBS 29.1以降）。

OBSのシーンや利用者の素材は自動削除しません。共通の初期アバターは重ね合わせ対象外です。実際のDiscord画像・発言状態はOBSで確認してください。
