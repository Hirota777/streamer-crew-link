# 0.3.0 実装・検証記録

確認日：2026年11月13日。非公開Streamkit版のみが対象です。

- 表示方式をクルーのみ／Discord画像と合わせるに整理しました。OBS連携の開始・停止を上部へ移しました。
- メンバー／見た目は独立して保存・切替・名前変更・複製・削除・書き出し・追加読み込みできます。
- 保存前の設定を暗号化したまま3世代保持し、日時を指定して復元します。全削除は内部バックアップも削除します。
- OBSと同じCSSで番号入りの仮画像を使って見本を表示します。公式画像や通話人数は取得しません。
- 丸・角丸・四角、名前背景の濃さ、動きの強さ、任意の起動時OBS連携を追加しました。
- デモの3／6／11人と発言中の見本は配信へ送信しません。クルーのみの配信用イベントも実ゲーム専用です。
- 縦表示のクルーは左側固定、横表示は上側を維持しました。死亡情報の読取・公開タイミングは変更していません。

単体・サーバー・Luaホスト模擬テスト129件、画面テスト22件が成功しました。Windowsのパッケージから分離したテスト用設定で2回起動し、保存・再起動・ネイティブ書き出し・任意の自動開始・暗号化・終了時の連携停止を確認しました。MSIの同梱データを検査し、設定・認証情報・開発テストの混入がないことを確認しました。

今回の確認では実際のゲーム・Discord通話・複数人の発言を通した一連の確認はしていません。0.2.1の1人の公式画像によるOBS確認は OBS-VALIDATION.md を参照してください。画面の登録数と連携ファイル更新状態を、実際の通話人数・OBS表示成功とは案内しません。

公開版の設定、認証、リポジトリ、リリースは変更していません。非公開版のMSIを作成し、リリース公開は行いません。

今後の再確認範囲と未完了項目は [検証方針](TEST-POLICY.md) に従います。
