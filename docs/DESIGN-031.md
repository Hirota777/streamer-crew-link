# 0.3.1 管理画面の見直し

2026年11月13日。非公開Streamkit版のみが対象です。

状態表示を一つの帯にまとめ、プリセットは見出し・選択欄・管理操作を揃えました。タブの選択状態を面の色で区別し、表示の見本の説明をパネル内へまとめました。管理画面の文字・入力・保存ボタンを読みやすくしました。

見た目の設定は「配置とサイズ」「名前」「クルーと状態」「発言時の動き」に分類しました。表示方式により項目がすべて非表示になるグループは隠します。縦表示のクルーは左固定を維持します。

OBSの出力スタイルとゲームの死亡更新、保存形式は変更していません。既存のプリセットはそのまま利用します。配信前チェック・原因案内パネル・OBSサイズ案内は追加していません。

単体・サーバー・Lua模擬テスト129件と画面テスト22件が成功しました。560・780・1200pxの幅で全3タブにページ全体の横はみ出しがないこと、ID重複・画面内エラーがないことを確認しました。必要に応じて表の内部は横スクロールできます。Windowsの暗号化・再起動の手動再確認は、保存・ネイティブ処理を変更していないため省略し、0.3.0の確認を基準とします。実ゲームと複数人のDiscord通話を通した確認は未実施です。
