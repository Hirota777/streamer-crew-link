# Streamer crew link v1.1.6

公式Discord Streamkit方式の改善版です。通常版・Nebula・SNRと「クルーのみ」表示も引き続き利用できます。

## 主な変更

- 表示方式の初期値を「Discord画像と合わせる」に変更。保存済みの表示方式は維持します。
- 新規設定では、表示方式と保存済みStreamkit URLが揃うとOBS連携を自動開始します。次回起動時も自動再開します。以前に自動開始をオフにしている場合は、初期設定の「設定済みならOBS連携を自動で開始する」をオンにしてください。
- OBS連携の開始・一時停止を初期設定内へ移動しました。一時停止や設定一式の読み込み後は、保存操作で勝手に再開しません。
- デモを11人固定にし、人数選択を削除しました。
- 起動直後にタブ操作が効かない場合がある問題と、全削除後に編集中の古いメンバー欄が残る問題を修正しました。
- MSIの利用規約と同梱文書を現行方式へ整理し、通常更新での設定保持と初回移行時の削除条件を区別しました。

## 更新時の注意

現行方式の初期化完了記録がある環境では、保存済みの設定・対応づけ・表示先を保持します。初期化完了記録がない旧方式・検証版からの初回移行では、アプリ起動時に既知の旧設定削除への同意を求める場合があります。MSI自体で設定フォルダーやOBSのシーンを削除する構成ではありません。

配信終了後にアプリを閉じてMSIを実行してください。ZIPは展開して使用します。必要に応じて「設定一式を書き出す」で設定を保管できます。書き出したJSONにはユーザーIDやURLが含まれるため、公開・共有しないでください。

## 検証と制約

単体・サーバー等169件と画面48件、計217件の自動テストが成功しました。MSIをインストールせず展開し、40ファイルの一致、設定保存先を削除しない構成、規約の日本語本文、個人パス等の混入がないことを確認しています。npmおよび.NET依存部品の監査では既知の脆弱性は報告されていません。

MSI・アプリは未署名です。複数人の実ゲーム・通話・OBSを通した一連の実機確認は今回未実施です。Discordの画像や発言状態はOBS内の公式Streamkitが表示し、このアプリが公式ウィジェットの内部情報を取得する仕組みではありません。既存の導入手順書・仕様書はリポジトリのdocsで公開し、アプリの配布ファイルには同梱しません。
