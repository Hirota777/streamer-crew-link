# Streamkit 0.1.0 実装と確認結果

2026年11月13日。非公開検証版。

## 実装した機能

- 公式Voice表示用URLの入力・検証・メンバープリセット保存・コピー・解除。
- パラメーターを保ったままWindowsで暗号化保存し、アプリ再起動後も復元。
- メンバープリセットと配信画面プリセットの独立した切替・保存。別名保存時にURLも複製し、元のプリセットを上書きしない。
- 未保存URLを持った状態での切替防止、別画面からの切替時の退避・復元。
- デモ中のURL保存で実際のメンバー対応づけを変更しない。
- URLの保存だけでは外部ページへ接続せず、通話が接続済みであるとも表示しない。

## 公開版との分離

製品名・設定保存先・インストール先は `Streamer crew link Streamkit Dev`。待受は `127.0.0.1:37901`。MSIのUpgradeCodeは `B96A482A-0579-4D1E-9F52-AEE8ED1B7C16`。公開版からのデータ・認証の移行は行わず、公開版の設定先を検証版の保存先として使用することも拒否する。

自動更新の起動・IPCを取り外し、残っている更新ライブラリの参照先も非公開リポジトリへ分離した。RPCの自動接続・ユーザーからの接続要求は無効。旧処理の単体検査に限り、テスト用クライアントと明示したオプションで検査する。

## 検証

単体・サーバーテスト115件、画面テスト16件が合格。追加テストで不正ドメイン、認証情報付きURL、設定用URL、Chat URL等の拒否、暗号化保存、プリセットの独立、コピー、解除、デモ、未保存編集を確認した。

Windows実行版を専用の空プロファイルで2回起動し、実際のWindows暗号化でURLを保存・復元できること、公開版の更新UI・RPC画面が出ないことを確認した。検査では架空のURLを使用し、公式Streamkitの認証や通話表示は操作していない。

## 未実装・未検証

公式ウィジェットの埋め込み、内部の参加者・発言状態の取得、クルーとの自動合成は未実装。OBSでの実際の公式URL表示・公式認証・複数人通話の確認、MSIを使った実インストールは未実施。

この版の完了範囲はURL管理と公開版からの分離であり、従来のRPC表示機能を完全に置き換えたものではない。公開版・v1.0.5の下書きリリースへこの変更を反映しない。
