# Streamer crew link v1.1.8

## 連携エラー時のちらつき軽減

- OBSスクリプトは、連携ファイルの欠落・読取失敗・不正な内容・古いハートビートで、最後に適用した正常なURL・CSS・寸法を保持します。エラーを理由に元のURLや空白へ戻しません。
- 復旧時に同じURL・CSS・寸法ならソースを更新しません。内容が変わった場合は、変わった項目だけを適用します。
- 正常な停止通知、OBS側の同期解除、スクリプトの読み込み解除では、従来どおり元の設定へ戻します。
- 自動復旧の待機中にアプリを正常終了した場合も、停止通知の書き込みを試みます。

更新後、OBSの「ツール → スクリプト」で `streamer-crew-link.lua` を再読み込みしてください。アプリがスクリプトファイルを更新しても、OBSに読み込み済みの処理は自動で切り替わりません。

保持対象はアプリが適用した配信設定です。公式Streamkit自体の通信断による参加者表示の変化や、OBSのシーン／ソースを利用者が操作した場合の非表示まで防ぐものではありません。エラー中のゲームの色・生死は最後の正常な情報のままになるため、復旧後に更新されます。
