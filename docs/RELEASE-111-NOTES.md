# Streamer crew link v1.1.1

クルー画像とアプリアイコンを、出典を確認したAmongUsCaptureのPlayers素材へ差し替えました。

## 変更点

- 生存・Deadの画像を差し替え。元の12色に、同じ素材から色変更した追加6色を加え、18色に対応。
- Nebula・SNRの追加色も、新しい素材を使って変換・表示。
- Dead画像の薄い背景を透明化し、白縁で四角い背景が見える問題を防止。
- アプリアイコンを同じ素材から作り直し。
- 素材の出典・著作権表示・MIT原文を同梱。ライセンス画面から確認できます。

## 更新と保存先

v1.1.0で保存した設定は引き継ぎます。本体・設定・OBS連携ファイルの保存場所は従来どおりです。検討していた保存先の1フォルダー化は含めていません。

v1.0系から初めてv1.1系へ更新する場合は、初回確認後に旧設定を初期化する仕様です。配信終了後にアプリを閉じ、MSIを実行してください。ゲームとDiscordは終了不要です。ZIP版も添付しています。Source codeは実行用ではありません。

## 検証と既知の不具合

単体156件・画面44件、計200件成功。Windowsの画像変換を確認し、MSIの40ファイルが配布アプリと一致することを検証しました。

次の2件は本版では未修正です。

1. デモ表示中、実ゲームの更新や保存した表示方式がOBSへ反映されず、デモ終了後に反映される。配信中はデモを使わず通常表示で操作してください。
2. 複数の設定画面で同じ見た目を編集すると、後の保存で別画面の変更を古い値へ戻すことがある。見た目の編集は1つの設定画面で行ってください。

実ゲーム・複数人の通話・OBSを通した一連の動作確認は未完了です。CSS変更時のOBSの一瞬の再表示は残ります。
