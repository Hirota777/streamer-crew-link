# 0.7.0 画面構成の整理

- 配信画面タブの先頭に見た目プリセット・管理・別名保存・「保存」をまとめた。共通ヘッダーのプリセットと下部固定の保存バーは廃止。未保存変更の取り消しは共通ヘッダーで操作できる。
- メンバーの解除ボタンをDiscord ID入力欄と同じ行へ配置。登録済みの重複表示を除き、自動保存・再試行は維持。
- 常時表示の長い説明と各設定グループの重複説明を削除。OBS初回手順は短縮し、ユーザーID取得・同期の注意は折りたたみに残した。
- 設定は幅に応じて横並びにし、狭い画面では折り返す。管理画面だけにCSSを限定し、配信出力の寸法・位置は変更していない。
- 単体137件・画面33件、合計170件成功、スキップなし。追加した画面テストでは幅560・780・1200で3タブの外側にはみ出しがないこと、保存とプリセットが配信画面だけに表示されること、IDと解除の中央位置が同じであることを検証。
- 画面画像で780幅の配信画面・メンバー・設定展開状態を確認。OBS表示、複数画面の未保存保護、遅延応答、URL登録と保存の既存テストも成功。
- 利用者の起動中アプリ・ゲーム・Discord・OBSは終了していない。保存形式とWindows暗号化処理は変更せず、既存の確認を繰り返していない。
