# v1.1.2 設定引き継ぎ・更新通知の検証

確認日：2026年11月18日。配布候補を作成。公開・インストール・利用者アプリの再起動は未実施。

## 変更

- 初期設定から、保存済みの対応づけ・表示先URL・見た目プリセット・選択状態・OBS自動開始の設定を一つのJSONへ書き出す。デスクトップでは任意の保存先を選ぶ。
- 読み込みは内容の件数を確認後、現在の設定を置き換える。OBS連携とデモを停止する。認証情報・暗号化キー・OBS側の設定・更新履歴は対象外。
- 読み込み確認後に保存内容が変わった場合は競合として拒否する。古い編集要求は内部IDの再生成で拒否する。不正形式・書き込み失敗では元の設定を維持する。
- 「あとで」は次回起動時に再通知。「スキップ」は同じ版の自動通知を停止する。手動確認と次の新しい版は対象外。処理後の案内とスキップ中の版の表示を追加。
- 保存先はAppDataのまま。ZIPフォルダー削除による設定消失の個別原因までは確定していない。

## 結果

- 単体・サーバーテスト164件、画面テスト47件、計211件成功。
- Windowsの実際の暗号化を使用し、書き出し元と異なる保存プロファイルへ読み込み、再起動後も保持することを確認。利用者の設定には触れていない。
- ファイル選択のキャンセル・不正JSON・上限超過・未保存編集・外部変更による競合を確認。
- 追加画面と読み込み確認ダイアログの見た目を確認。
- MSIの40ファイルを管理用展開し全ハッシュがパッケージと一致。製品名・版・ユーザー単位インストール・既存UpgradeCodeを確認。インストール状態を変更せず、設定フォルダーを削除する規則がないことを確認。
- app.asar内の新規機能・変更ファイルがソースと一致。利用者設定・認証・テストデータの混入なし。
- MSIとZIPを作成。署名なし。ハッシュはdist/SHA256SUMS-1.1.2.txtに記録。
