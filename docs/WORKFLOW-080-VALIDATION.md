# 0.8.0 操作改善4項目

## 実装

1. 未設定人数のクリックでメンバータブの要確認一覧へ移動。ゲーム内の未登録・不正ID・表示OFFを区別。表示OFFだけの絞り込みと全表示も提供。0人・全員対応済み・クルーのみ・デモでは未設定ボタンを無効化する。
2. 登録済みメンバーの名前をドラッグして配信順を変更し、自動保存。実際の配信順番号と矢印も維持。ゲーム内優先の表の並びを維持し、ドラッグ中はイベント配信でDOMを置き換えない。デモは操作不可。
3. 見た目の「元に戻す」を配信画面の保存隣へ移動し、見た目だけを戻す。初期設定にはURLと表示先名を戻す専用操作を配置。他方の未保存編集を保護する。
4. 発言時の高さを0〜32pxで指定するスライダー。旧版の強度は旧アイコンサイズから高さへ変換し、読み込み・プリセット・再起動後も引き継ぐ。明示した高さはアイコンサイズに連動せずpxで保持。見本へ即時、OBSへは保存後に反映。既存の枠内余白計算も高さを使用。

## 検証

単体143件・画面42件、計185件成功。新規6件で設定移行と範囲検証、未登録・表示OFF・不正IDの区別、ゲームのみの無効化、Playwrightの実際のdragTo操作、自動保存と再読込、デモ中の操作制限、取り消しの分離、高さの即時反映と保存を確認。幅560・780・1200で未保存時のボタンが外にはみ出さないことも確認。

画面確認後に絞り込みを見出し内へ集約し、全画面テスト42件を再実行。最大32pxの動きと40pxのアイコンでも枠内に収まることを確認。競合防止・全削除・OBS出力の既存テストも維持。

合成データと独立保存先のみを使用。利用者の起動中アプリ・ゲーム・Discord・OBSは変更せず、ゲームフォルダーへの追加も行わない。暗号化形式の変更はない。実ゲームと複数人通話・実発言を通した確認は未実施。
