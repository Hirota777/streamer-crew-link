# 0.6.0 対応づけの自動保存と設定バックアップ廃止

- 対応づけ・配信用の名前・表示対象・配信順は入力後に自動保存する。日本語変換中は確定を待つ。保存失敗時は編集を保持し、再試行できる。
- メンバー保存・両方保存ボタンを削除。見た目と名前付きStreamkit表示先の保存は独立して維持する。
- 設定バックアップの生成・一覧・復元画面とAPIを削除。旧ファイルは更新時に消さず、明示的な全削除時だけ既知のファイル名を掃除する。OBSソースを元へ戻す機能は維持する。
- 自動テスト137件、画面テスト32件、合計169件成功（スキップなし）。遅延応答中の再編集、保存失敗と再試行、頻繁なゲーム更新、IME確定、別画面での全削除後に古い保存が届くケースを含む。
- Windows独立テスト用プロファイルで暗号化保存・再起動後の保持・バックアップを生成しないこと・全削除時の既知ファイル限定削除を確認。実ユーザーの設定や暗号化キーはコピーしない。
- 幅560・780・1200の3タブ、計9画面で横のはみ出しと画面エラーがないことを確認。
- 起動中の利用者アプリ、ゲーム、Discord、OBSは終了・変更していない。実ゲームの死亡判定やOBS同期処理は変更していない。
