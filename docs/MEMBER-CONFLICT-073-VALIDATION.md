# 0.7.3 自動保存の競合と保存エラー残留の修正

## 修正

- メンバー自動保存で編集前の対応づけを送信し、保存キュー内で最新設定と比較する。別メンバー・別フィールドの更新は統合し、同じフィールドの異なる更新、削除と編集、異なる配信順変更、Discord ID重複は409/MEMBER_CONFLICTで拒否する。新旧の追加・解除を黙って巻き戻さない。保存形式は変更しない。
- 競合した画面の入力は保持する。「最新の設定を使う」は競合時のみ表示し、確認後に対応づけの編集だけを破棄して最新設定を取得する。見た目・URLの未保存編集は維持する。
- 自分の前回保存の応答待ちにさらに編集した場合も、次回の比較元を更新して連続保存を妨げない。
- 全削除等によるメンバー保存先変更を受信したら、以前の保存エラー・競合・入力変換状態・保存待機タイマーを初期化する。

## 検証

単体141件・画面37件、計178件成功、スキップなし。追加7件では再現済みの2件に加え、同一項目の競合、別項目の統合、削除済みメンバーの復活防止、追加・重複ID・配信順の競合、再読込による保持、エラー解消後の新規登録を確認。既存の遅い応答中の連続編集も成功。

利用者の設定をコピーせず、合成データ・独立した保存先を使用。起動中アプリ・ゲーム・Discord・OBSは終了しない。暗号化と保存形式は変更していないため、過去に確認済みの同一Windows暗号化操作を繰り返さない。実ゲーム＋複数人通話の再確認は未実施。
